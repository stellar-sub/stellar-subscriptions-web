# Stellar Subscriptions Web

The web app for Stellar Subscriptions: plans, subscriptions and charge caps,
backed by Soroban contracts and signed with Freighter.

## Development

```bash
npm install
npm run typecheck
npm run lint
npm test
npm run build
```

## Contributing

- Read the [Code of Conduct](CODE_OF_CONDUCT.md) before taking part.
- Changes to contract bindings and subscription code are reviewed by the
  owners listed in [`.github/CODEOWNERS`](.github/CODEOWNERS).
